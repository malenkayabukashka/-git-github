## 2. Основы Git
### VCS (Visual Control System) - софт, для:
- поддерживает несколько версий кода
- откат к прошлым версиям
- определить автора кода

### Типы VCS
- Локальные (одна машина ни с кем не синхронизуется - Revision Control System, мало актуально)
- Централизованные (есть сервер с репозиторием, откуда все всё качают - Subversion, CVS, риск потери всего)
- Распределенные (есть сервер, но каждый участник имеет свою копию репозитория - Git, Mercurial)

### Команды
вызов краткой справки / проверка установки Git

git
